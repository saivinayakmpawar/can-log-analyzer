CAN Log Analyzer

Upload a DBC file and a CAN log (.asc, .log, .csv or .blf). The app decodes every signal, plots it, and flags missing messages, out-of-range values and unknown IDs. With only a DBC file, it shows what the database defines.

Only a DBC file chosen? Analyze shows its messages and signals instead.
